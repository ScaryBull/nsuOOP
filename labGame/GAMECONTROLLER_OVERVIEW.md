# GameController: описание и функции

## Назначение класса
`GameController` — центральный контроллер игры. Он связывает модель (`GameModel`), представление (`GameView`) и пользовательский ввод. Отвечает за обработку событий, управление состояниями игры, создание и обработку предметов, переходы между окнами и экранами.

## Основные поля
- **model** — объект модели игры (`GameModel`), хранит все данные и логику предметов, уровней, инвентаря и т.д.
- **view** — объект представления (`GameView`), отвечает за отрисовку.
- **itemCells** — массив указателей на предметы в ячейках (слоты для предметов).
- **selectedIngredients** — индексы выбранных ингредиентов для создания зелья.
- **selectedPotionsForAmulet** — индексы выбранных зелий для создания амулета.
- **selectedPotionsForStar** — индексы выбранных зелий для создания звезды.
- **allSlots** — координаты всех слотов на экране.
- **Флаги состояния**: showPotion, showShop, showOrders, showTrash, showSecretWindow, showBlackScreen, showMenuOverlay, amuletBaseSelected, starSelected.

## Ключевые функции
- **GameController()** — конструктор, инициализирует модель, представление и начальные состояния.
- **mixIngredients(const std::vector<int>& ingredients)** — смешивает ингредиенты, возвращает индекс результата.
- **refundSelections()** — отменяет выборы пользователя, возвращает ингредиенты и амулеты на место.
- **handleEvents(sf::RenderWindow& window)** — главный обработчик событий окна (мышь, закрытие и т.д.).
- **handleShelfClick(float mouseX, float mouseY)** — обработка кликов по полкам с ингредиентами и слотам зелий/амулетов.
- **handleCauldronClick, handleShopClick, handleOrdersButtonClick, handleTrashButtonClick** — обработка кликов по основным кнопкам интерфейса.
- **handleShopBuy, handleOrderClick, handleTrashPotionClick, handleBlackScreenClick** — обработка действий в соответствующих окнах.
- **draw(sf::RenderWindow& window)** — вызывает отрисовку текущего состояния через GameView.

## Подробное описание функций GameController

### GameController()
Конструктор. Инициализирует модель, представление, массивы предметов и состояния интерфейса. Очищает все списки выбранных предметов и сбрасывает флаги.

### mixIngredients(const std::vector<int>& ingredients)
Смешивает выбранные ингредиенты (по индексам) и возвращает индекс результата. Используется для генерации уникального результата на основе выбранных ингредиентов.

### refundSelections()
Отменяет все текущие пользовательские выборы:
- Возвращает ингредиенты обратно в инвентарь.
- Возвращает базу амулета и звезду, если они были выбраны.
- Очищает списки выбранных зелий для амулета и звезды.

### handleEvents(sf::RenderWindow& window)
Главный обработчик событий окна:
- Обрабатывает закрытие окна.
- Обрабатывает клики мыши: определяет, по какому элементу интерфейса кликнул пользователь, и вызывает соответствующую функцию (handleShopClick, handleShelfClick и т.д.).
- Управляет переходами между окнами (магазин, заказы, мусорка, котёл и т.д.).

### handleShelfClick(float mouseX, float mouseY)
Обрабатывает клики по полкам с ингредиентами и слотам зелий/амулетов:
- Позволяет выбирать ингредиенты, зелья для амулета/звезды.
- Управляет логикой создания амулета и звезды.
- Реализует механику выбора и отмены выбора предметов.

### handleCauldronClick(float mouseX, float mouseY)
Обрабатывает клики по котлу:
- Открывает/закрывает окно смешивания зелий.
- Сбрасывает выборы при необходимости.

### handleShopClick(float mouseX, float mouseY)
Обрабатывает клики по кнопке магазина:
- Открывает/закрывает магазин.
- Сбрасывает выборы и состояния, если нужно.

### handleShopBuy(float mouseX, float mouseY)
Обрабатывает покупку предметов в магазине:
- Проверяет, достаточно ли золота.
- Добавляет предмет в инвентарь или открывает новый уровень/секрет.

### handleOrdersButtonClick(float mouseX, float mouseY)
Обрабатывает клики по кнопке заказов:
- Открывает/закрывает окно заказов.
- Сбрасывает выборы и состояния.

### handleOrderClick(float mouseX, float mouseY)
Обрабатывает выполнение заказа:
- Сравнивает свойства предмета в слоте с требованиями заказа.
- Если совпадает — удаляет предмет, начисляет золото, генерирует новый заказ.

### handleTrashButtonClick(float mouseX, float mouseY)
Обрабатывает клики по кнопке мусорки:
- Открывает/закрывает окно удаления предметов.
- Сбрасывает выборы и состояния.

### handleTrashPotionClick(float mouseX, float mouseY)
Обрабатывает удаление зелья из слота мусорки.

### handleBlackScreenClick(float mouseX, float mouseY, sf::RenderWindow& window)
Обрабатывает клики по кнопкам на чёрном экране (Restart, Continue, Exit):
- Перезапускает игру, продолжает или закрывает окно.

### draw(sf::RenderWindow& window)
Вызывает отрисовку текущего состояния игры через GameView, передавая все необходимые данные (выбранные предметы, состояния окон и т.д.).
