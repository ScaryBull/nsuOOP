# GameView: описание и функции

## Назначение класса
`GameView` — отвечает за визуализацию состояния игры. Этот класс реализует отрисовку всех элементов интерфейса: игрового поля, предметов, окон магазина, заказов, мусорки, кнопок, текста и т.д. Также занимается загрузкой ресурсов (текстур, шрифтов).

## Основные поля
- **Текстуры**: backgroundTexture, shelfTexture, cauldronTexture, potionTexture, mixButtonTexture, potionResultTexture, amuletResultTexture, shopButtonTexture, ordersButtonTexture, trashButtonTexture, menuButtonTexture, ingredientTextures[], level2Texture, level3Texture, amuletTexture, secretTexture, starTexture и др.
- **Шрифт**: font — основной шрифт интерфейса.
- **Параметры интерфейса**: размеры, координаты, отступы, размеры ячеек, кнопок и т.д.

## Ключевые функции
- **GameView()** — конструктор, загружает все текстуры и шрифты, инициализирует параметры интерфейса.
- **loadTextureOrThrow, loadTextureFromFile, loadFontOrThrow** — служебные функции для загрузки ресурсов с обработкой ошибок.
- **draw(sf::RenderWindow&, const GameModel&, ...)** — главная функция отрисовки, вызывает все остальные draw-функции в зависимости от состояния игры.
- **drawShelves, drawShelfHook, drawButtons, drawPotionWindow, drawPotionSlots, drawShopWindow, drawTrashWindow, drawOrdersWindow, drawTopBar, drawSecretModal, drawBlackScreenOverlay** — функции для отрисовки отдельных частей интерфейса.
- **makeSprite, makeText, makeRect** — вспомогательные функции для создания спрайтов, текста и прямоугольников с нужными параметрами.

## Подробное описание функций GameView

### GameView()
Конструктор. Загружает все необходимые текстуры и шрифты, инициализирует параметры интерфейса. Если какой-либо ресурс не найден — выбрасывает исключение.

### loadTextureOrThrow(sf::Texture&, const std::string& path)
Загружает текстуру из файла. Если не удалось загрузить — выбрасывает исключение с описанием ошибки.

### loadTextureFromFile(sf::Texture&, const std::string& path)
Пытается загрузить текстуру из файла, возвращает true/false по успеху. Используется для необязательных ресурсов.

### loadFontOrThrow(sf::Font&, const std::string& path)
Загружает шрифт из файла. Если не удалось загрузить — выбрасывает исключение.

### draw(sf::RenderWindow&, const GameModel&, ...)
Главная функция отрисовки. Вызывает все остальные draw-функции для отображения текущего состояния игры: полки, предметы, окна, кнопки, текст и т.д.

### drawShelves(...)
Отрисовывает полки с ингредиентами и размещает предметы на них.

### drawShelfHook(...)
Отрисовывает крюк и базу амулета, если они доступны.

### drawButtons(...)
Отрисовывает основные кнопки интерфейса (котёл, магазин, заказы, мусорка и т.д.).

### drawPotionWindow(...)
Отрисовывает окно создания зелья или амулета, выбранные ингредиенты/зелья, кнопки смешивания.

### drawPotionSlots(...)
Отрисовывает слоты для зелий в инвентаре игрока.

### drawShopWindow(...)
Отрисовывает окно магазина: доступные ингредиенты, уровни, амулеты, секреты, цены.

### drawTrashWindow(...)
Отрисовывает окно мусорки для удаления предметов.

### drawOrdersWindow(...)
Отрисовывает окно активных заказов и их требования.

### drawTopBar(...)
Отрисовывает верхнюю панель: уровни, золото, секрет.

### drawSecretModal(...)
Отрисовывает модальное окно с секретом (финальная цель игры).

### drawBlackScreenOverlay(...)
Отрисовывает чёрный экран с финальным сообщением и кнопками (Restart, Continue, Exit).

### makeSprite(...), makeText(...), makeRect(...)
Вспомогательные функции для создания спрайтов, текста и прямоугольников с нужными параметрами (позиция, размер, цвет, выравнивание и т.д.).

## Примеры сценариев
- **Отрисовка игрового поля:**
  - Вызов draw() приводит к последовательной отрисовке всех элементов: фона, полок, предметов, кнопок, окон и т.д.
- **Загрузка ресурсов:**
  - При создании GameView все текстуры и шрифты загружаются с диска. Если что-то не найдено — выбрасывается исключение.
- **Обновление интерфейса:**
  - При изменении состояния модели (например, добавлен предмет, куплен ингредиент) контроллер вызывает draw(), и GameView отображает актуальное состояние.

## Взаимодействие с другими классами
- Получает данные для отрисовки из GameModel (через параметры draw-функций).
- Не изменяет модель напрямую — только отображает.
- Используется GameController для визуализации всех изменений.

## Особенности реализации
- Использует SFML для работы с графикой и текстом.
- Все ресурсы (текстуры, шрифты) загружаются один раз при создании объекта.
- Вспомогательные функции позволяют легко масштабировать и позиционировать элементы интерфейса.
- Вся логика отрисовки разделена на отдельные draw-функции для удобства поддержки и расширения.
