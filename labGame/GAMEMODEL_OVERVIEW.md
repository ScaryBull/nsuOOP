# GameModel: описание и функции

## Назначение класса
`GameModel` — это основная модель данных игры. Хранит и управляет всеми игровыми сущностями: ингредиентами, зельями, амулетами, уровнями, заказами, инвентарём, золотом, состоянием секретов и т.д. Вся логика изменения состояния игры реализована здесь.

## Основные поля
- **allIngredients** — вектор всех доступных ингредиентов (std::vector<std::shared_ptr<Item>>).
- **inventory** — карта (map) количества каждого ингредиента у игрока.
- **craftedPotions** — вектор всех созданных зелий.
- **activeOrders** — вектор текущих заказов.
- **unlockedLevels** — вектор открытых уровней.
- **availableLevels** — вектор всех возможных уровней.
- **gold** — текущее количество золота у игрока.
- **amuletBases** — количество баз для амулетов.
- **starCount** — количество звёзд.
- **secretPurchased** — куплен ли секрет.
- **rng** — генератор случайных чисел для случайных событий.

## Ключевые функции
- **GameModel()** — конструктор, инициализирует все поля, вызывает функции инициализации ингредиентов, инвентаря, уровней и заказов.
- **initializeIngredients()** — создаёт и заполняет allIngredients на основе предопределённых данных.
- **initializeInventory()** — заполняет инвентарь начальными количествами ингредиентов.
- **initializeLevels()** — инициализирует уровни и открывает первый уровень.
- **regenerateOrdersForLevel()** — генерирует новые заказы для текущего уровня.
- **addPotion(const std::shared_ptr<Item>&)** — добавляет зелье в коллекцию созданных.
- **addGold(int amount), getGold()** — управление золотом.
- **getIngredientQuantity, setIngredientQuantity, decrementIngredient** — управление количеством ингредиентов.
- **getIngredient(int index)** — получить указатель на ингредиент по индексу.
- **unlockLevel, hasLevel, getUnlockedLevels** — управление уровнями.
- **getAmuletBases, setAmuletBases, decrementAmuletBase** — управление базами амулетов.
- **purchaseSecret, isSecretPurchased** — управление секретом.
- **addStar, getStarCount, decrementStar** — управление звёздами.
- **getLevelUnlockPrice, getAmuletBasePrice, getSecretPrice, getStarPrice** — получение цен на разные объекты.
- **pickUniqueIngredientProperties(int count)** — выбирает уникальные свойства ингредиентов для заказа.
- **generateNewOrder(int orderIndex)** — создаёт новый заказ с уникальными свойствами.
- **removeOrder(size_t index)** — удаляет заказ по индексу.
- **computeOrderSpec(int orderIndex)** — вычисляет параметры заказа (количество свойств, тип предмета).

## Подробное описание функций GameModel

### GameModel()
Конструктор. Инициализирует генератор случайных чисел, вызывает функции инициализации ингредиентов, инвентаря, уровней и заказов.

### initializeIngredients()
Создаёт и заполняет вектор allIngredients на основе предопределённых данных (имя, свойство, цена, множитель, картинка). Использует фабрику для создания объектов и метод load для заполнения полей.

### initializeInventory()
Заполняет инвентарь начальными количествами каждого ингредиента.

### initializeLevels()
Создаёт список всех уровней, открывает первый уровень, добавляет его в unlockedLevels.

### regenerateOrdersForLevel()
Очищает список заказов и генерирует новые заказы для текущего уровня.

### addPotion(const std::shared_ptr<Item>& potion)
Добавляет зелье в коллекцию созданных зелий.

### addGold(int amount), getGold()
Управление золотом игрока: добавление и получение текущего количества.

### getIngredientQuantity(int index), setIngredientQuantity(int index, int quantity), decrementIngredient(int index)
Получение, установка и уменьшение количества ингредиента в инвентаре.

### getIngredient(int index)
Возвращает указатель на ингредиент по индексу из allIngredients.

### unlockLevel(const AlchemyLevel& level), hasLevel(int level), getUnlockedLevels()
Открытие нового уровня, проверка наличия уровня, получение списка открытых уровней.

### getAmuletBases(), setAmuletBases(int quantity), decrementAmuletBase()
Получение, установка и уменьшение количества баз для амулетов.

### purchaseSecret(), isSecretPurchased()
Покупка и проверка наличия секрета.

### addStar(int amount), getStarCount(), decrementStar()
Добавление, получение и уменьшение количества звёзд.

### getLevelUnlockPrice(int level), getAmuletBasePrice(), getSecretPrice(), getStarPrice()
Получение цен на открытие уровня, покупку базы амулета, секрета и звезды.

### pickUniqueIngredientProperties(int count)
Выбирает уникальные свойства ингредиентов для генерации заказа (случайным образом).

### generateNewOrder(int orderIndex)
Создаёт новый заказ с уникальными свойствами и типом предмета.

### removeOrder(size_t index)
Удаляет заказ по индексу из списка активных заказов.

### computeOrderSpec(int orderIndex)
Вычисляет параметры заказа: сколько свойств требуется, какой тип предмета (зелье или амулет).

## Примеры сценариев
- **Создание ингредиентов:**
  - При запуске игры вызывается initializeIngredients(), которая создаёт объекты ингредиентов через фабрику и заполняет их данными.
- **Покупка ингредиента:**
  - При покупке увеличивается количество в inventory, уменьшается золото.
- **Выполнение заказа:**
  - При совпадении свойств предмета с заказом начисляется золото, генерируется новый заказ.
- **Переход на новый уровень:**
  - Открывается новый уровень, увеличивается максимальное количество ингредиентов, обновляются заказы.

## Взаимодействие с другими классами
- Используется GameController для получения и изменения состояния игры.
- Передаёт данные для отрисовки в GameView.
- Использует ItemFactory для создания предметов.

## Особенности реализации
- Все коллекции предметов и заказов реализованы через std::vector и std::shared_ptr для удобного управления памятью и полиморфизма.
- Вся логика изменения состояния инкапсулирована в методах модели.
- Использует генератор случайных чисел для случайных событий (выбор свойств, генерация заказов).
